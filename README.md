# Sales-Performance-Data

# 📊 Sales Performance Dashboard – Excel

## 📌 Project Overview

This project is an **Excel-based Sales Performance Dashboard** designed to analyze sales, profit, costs, customers, products, categories, regions, payment methods, and monthly performance.

---

## 🎯 Project Objectives

* Analyze overall sales and profit performance
* Track sales and profit trends
* Identify top-performing products and categories
* Compare sales performance across regions
* Analyze customer performance
* Monitor quantity sold and revenue
* Evaluate costs and profit margins
* Understand the impact of discounts
* Analyze payment methods
* Present key business KPIs through an Excel dashboard

---

## 📂 Dataset

The dataset contains **80 sales transactions** with **16 analytical fields**.

### Key Columns

| Column          | Description                   |
| --------------- | ----------------------------- |
| Order_ID        | Unique order identifier       |
| Order_Date      | Date of the order             |
| Customer        | Customer identifier           |
| Product         | Product purchased             |
| Category        | Product category              |
| Region          | Sales region                  |
| Quantity        | Number of units sold          |
| Unit_Price      | Price per unit                |
| Discount_%      | Discount applied              |
| Payment_Mode    | Payment method                |
| Sales           | Total sales/revenue           |
| Cost            | Cost associated with the sale |
| Profit          | Profit generated              |
| Month           | Month of the transaction      |
| Month_No        | Numerical month               |
| Profit Margin % | Profit margin percentage      |
